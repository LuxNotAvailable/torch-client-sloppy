# Token Optimization — torch-client

263K lines `src/`, 145K vendored (717 files). 15–20% generated data, 5–8% protocol boilerplate.

## 1. Generated Data (~35K lines, #1 bloat)

| File | Lines |
|------|-------|
| `generated_items.rs` | 15,304 |
| `copper_golem_anim.rs` | 4,730 |
| `warden_anim.rs` | 2,231 |
| `generated_block_sounds.rs` | 2,442 |
| `creaking_anim.rs` | 1,108 |
| `breeze_anim.rs` | 694 |
| `baby_axolotl.rs` | 1,407 |
| animals anims ×15+ | ~8,000 |

Pure data. No logic. Generated by `tools/gen_items.py`, `tools/protogen.py` etc.

**Fix:** Emit JSON/RON from generators. Keep struct defs (`ItemDef`, `Keyframe`, `SoundGroup`) in `types.rs`. Runtime loader ~50–100 lines. Delete `.rs` files from source.

**Risk:** Low. Audit `const` lookups → `HashMap<u32, &ItemDef>`. Slight startup parse cost.

## 2. Protocol Tables (~5K lines)

| File | Lines |
|------|-------|
| `hop.rs` | 2,670 |
| `v775.rs` | 1,285 |
| `remap.rs` | 384 |
| `packets.rs` | 356 |
| `wire.rs` | 248 |

Uniform pattern: `HopSpec` per version, rewrite fns 10–40 lines each.

**Fix:** Extend `protogen.py` to emit table entries as data. Keep only rewrite fn bodies in source. Add 20-line recipe at top of `hop.rs`: how to add a packet (3 steps).

## 3. Vendor (145K lines — keep out of context)

Patched `bevy_camera`, `simdnbt`, `azalea`. Patches ~10–50 lines/file; rest is upstream.

**Fix (pick one or combo):**
- `vendor/PATCHES.md` — which files, why, diff/PR link
- `git apply` in `build.rs` + `patches/*.patch` — source tree shows only diffs
- AGENTS.md rule: do NOT read `vendor/` unless debugging a crate

## 4. Module Boundaries

`src/` flat, 25 modules. `entities/` 19K+, `renderer/` 10K+, `vk/` 5K+, `protocol/` 5K+, `gui/` 5K+.

**Fix:**
- `//!` doc on every `mod.rs`: responsibility + entry points + what it does NOT do
- `docs/ARCHITECTURE.md` — 40 lines, module → responsibility → key types
- Split `renderer/` + `vk/` into separate crates (long-term)

## 5. Quick Wins (zero code change)

- **AGENTS.md** context rules (below)
- **`docs/ARCHITECTURE.md`** — highest-leverage single doc
- **GENERATED headers** on 4 largest generated files (3 lines each)
- **Search scope exclude:** `vendor/`, `generated_*.rs`, `*_anim.rs`, `dist/`, `android/` → removes ~180K lines from results

### AGENTS.md rules (paste)

```
## Context Rules
- Do NOT read vendor/ — see vendor/PATCHES.md
- Do NOT read generated_*.rs or *_anim.rs unless task is about data values
- Start: docs/ARCHITECTURE.md → target mod.rs
- Protocol: follow recipe at top of src/protocol/hop.rs
- Entities: read src/entities/mod.rs first
```

### GENERATED header (paste)

```rust
// GENERATED by tools/gen_items.py — do not edit.
// Data only: 15K item definitions. Schema in gen_items.py.
```
